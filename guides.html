Choose a LUT

Start with the clip’s recording profile. A conversion LUT turns camera log into SDR Rec.709. A creative LUT assumes the image is already in Rec.709 and changes its look.

Rec.709 footage or already converted to Rec.709
Use a Rec.709 creative LUT. Try Cobalt City for a blue night exterior or Honey Light for warm daylight.
Unconverted Apple Log 2
Use Apple Log 2 to Rec.709 for a neutral base, or pick a one-step look such as Apple Log 2 to Rec.709 – Sunwashed.
Unconverted original Apple Log
Use Apple Log to Rec.709, then add a separate creative LUT if you want a look.
HLG, PQ or another camera’s log
Use the matching camera or HDR transform to Rec.709 first. Then apply a Rec.709 creative LUT.

For control over intensity, use a neutral conversion once, then mix in a separate creative look. The one-step Apple Log looks already contain the conversion.

Blackmagic Camera

Set up the phone to capture a consistent image before you start grading.

  1. Choose a recording profile. In Settings › Record, select Apple Log 2 if the option is available and you want to grade in post. If the phone offers original Apple Log, match that profile in the editor. For quick turnaround, choose Rec.709 where available. Recording options depend on the device and codec.
  2. Pick resolution and frame rate. Try 4K at 25 fps for an SDR project in New Zealand. Under mains-powered lights, start at 180° shutter (1/50 s at 25 fps) and record a short test for flicker. Choose a codec your phone and editor handle comfortably. ProRes can take substantially more storage than HEVC.
  3. Set focus, white balance and exposure. Tap the controls in the camera HUD. Lock focus and white balance for a stable shot when the scene allows it. Use focus assist to check the subject and zebras or false colour to check bright areas. At night, watch the illuminated signs and keep enough light on the subject.
  4. Preview a LUT. Save and unzip the pack in Files. In the app’s LUTs settings, use Import LUT, select a matching conversion, and enable Display LUT. Leave Record LUT to Clip off if you want ungraded log files for editing.
  5. Check and transfer a test clip. Verify framing, flicker, focus and sound on a 10-second recording. In Media, share or copy the original files to your editing drive. Keep the originals together before importing them into the editor.

LUTs in Premiere Pro

  1. Set up the sequence for SDR. In Sequence › Sequence Settings › Color, choose Direct 709 (SDR) if available and check the output is Rec.709. Open Window › Lumetri Color.
  2. Check the source clip. Open Lumetri Color › Settings › Source Clip or right-click the source in the Project panel and open Modify › Color. Confirm the source profile. If Premiere already interprets and converts the log clip, proceed to the creative look.
  3. Manual conversion option. To use a Colour Studies conversion, select the matching file in the Source Clip › Input LUT controls and set its resulting media colour space to Rec.709. This treats the LUT’s output as Rec.709. Leave Preserve RGB off in this workflow and avoid adding the same conversion again under Basic Correction.
  4. Balance, then style. Select the timeline clip and use Edit › Basic Correction in Lumetri for temperature, tint and exposure. For a creative grade, use Creative › Look › Browse to choose a Rec.709 .cube. Try roughly 50% intensity first, then check the image and Lumetri Scopes. A one-step conversion already applies a look.

For a shared look across several already-balanced Rec.709 clips, apply the creative LUT to an adjustment layer above them. Keep clip-specific exposure and white balance on the clips.

LUTs in DaVinci Resolve

  1. Install the files. Unzip your download. Open Project Settings › Color Management › Lookup Tables › Open LUT Folder. Copy the .cube files into a Colour Studies folder, then click Update Lists in Resolve.
  2. Choose one conversion path. For a straightforward manual setup, use DaVinci YRGB and a Rec.709 SDR grading and viewing setup. On the Color page, right-click a node, open LUT, and choose the conversion that matches unconverted Apple Log or Log 2 footage. With Resolve Color Management already converting the shot, skip the conversion LUT. In wide-gamut workflows, reserve these creative LUTs for a point where the signal is Rec.709, such as a separate Rec.709 finishing pass.
  3. Give each adjustment a node. For log footage in a manual workflow, use one node to balance exposure and white balance, the next for the conversion, and the last for a creative Rec.709 LUT. On footage that is already Rec.709, balance it and apply the creative look on its own node.
  4. Control the blend. Select the creative node, open the Key palette, and reduce Output Gain, for example to 0.50. Toggle the node to compare and use the waveform and RGB parade to see what happens to the bright areas and shadows.

Your first Premiere edit

  1. Set up the project. Make a folder for media, audio, projects and exports. Back up the camera originals, then create a Premiere project. Import your clips and sort them into bins. Keep the source files in place so Premiere can find them.
  2. Make a sequence. Drag your main clip onto the New Item icon in the Project panel to start with matching settings. Check frame rate and frame size. For vertical delivery, create a 9:16 sequence and reframe each shot deliberately.
  3. Build a rough cut. Open a clip in the Source Monitor, mark the start and end with I and O, and assemble the selects on the timeline. Put the main action or dialogue on the first video track and place cutaways above it. Get the story working before adding transitions.
  4. Tighten the timing. Drag a clip edge for a normal trim. Use the Ripple Edit tool to move later clips as you trim, or right-click a gap and select Ripple Delete. Check the tracks affected by the edit. Use J, K and L to shuttle backward, stop and play forward.
  5. Make playback manageable. Lower Program Monitor playback resolution if the timeline stutters. For heavy footage, select source clips in the Project panel and choose Proxy › Create Proxies. Use the Toggle Proxies button while editing and keep the full-resolution files linked for export.

Try a 30-second practice cut. Use a wide shot to set the scene, a close detail, an action shot and a closing frame. A few seconds of room tone can help hide abrupt audio cuts.

Sound, captions and export

  1. Mix dialogue first. Open Window › Essential Sound and tag speaking clips as Dialogue. Set an even level by ear and watch the meters for clipping. Bring music and ambience up under the dialogue, then listen back with headphones.
  2. Add and proof captions. Open the Text panel and generate a transcript for the final sequence. Create captions from that transcript, check names and spelling, and inspect their timing on the timeline. Choose burned-in captions for a version with permanent text or export an SRT if the destination supports it.
  3. Export a review MP4. Open Export with Ctrl+M on Windows or ⌘+M on macOS. Use H.264 and start with Match Source – Adaptive High Bitrate. Verify the intended frame size, rate, audio, source range and Rec.709 output. For a higher-quality archive, consider a separate ProRes master.
  4. Watch the exported file. Check the start and end, audio balance, captions and a few cuts in an ordinary media player. For colour problems, compare the export in Premiere as well so you can isolate display differences from the export itself.

Troubleshooting

My clip looks washed out

Confirm its recording profile. If the image is still log, enable the matching colour-management transform or apply the matching conversion LUT. A creative Rec.709 LUT on its own expects a normalized image.

Shadows are crushed or highlights clip

Bypass the LUT and check whether the editor already converted the clip. A duplicate input conversion or a mismatch between Log and Log 2 can cause a big contrast or colour change. For a creative look, try less intensity and check the waveform.

It looked different on my phone

Check which LUT you used for monitoring and whether it was recorded to the clip. Also confirm the clip and sequence colour-space settings. A monitor preview and the final grade may use different transforms.

The LUT does not appear in the editor

Unzip the download and select a .cube file. In Resolve use Update Lists after copying it. In Premiere use Browse in the appropriate Lumetri menu.
