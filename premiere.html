Set up your project

Use five clips from the same place or activity. Gather an establishing shot, two details, a shot with movement and a closing shot. If the footage has no usable sound, record ten seconds of the location for ambience.

  1. Make a project folder. Create folders for original media, audio, Premiere projects and exports. Copy the camera files into the media folder before importing. Premiere links to them on disk, so keep the originals backed up.
  2. Import and organise. Create a new project, then use File › Import or drag the files into the Project panel. Create bins for Footage, Audio and Sequences. Give the edit a name such as Street Study 01.
  3. Make your sequence. Drag a representative clip to the Project panel’s New Item icon. In Sequence › Sequence Settings, verify the frame size and frame rate. For a first landscape project, matching your main clip is a useful starting point.

Build the rough cut

  1. Pull selects. Double-click a source clip. Shuttle with J, K and L, then press I at the start and O at the end of the usable action. Put that range onto the timeline.
  2. Lay out the main story. Start on V1 and A1. Try four seconds of the location, then a detail, the main action and a final frame. Aim for 30 seconds after trimming. Put optional cutaways on V2 so they can cover the main picture while its sound continues on A1.
  3. Try two ways to place a clip. With the source tracks patched and the timeline playhead at the edit point, , inserts the marked range and shifts later material on affected tracks. . overwrites the affected range for the duration of the new shot. Practise both on a duplicate sequence so you can see the difference.

Mute the music on your first review. The sequence should still make sense from the order of the shots and the movement within them.

Trim and reframe

  1. Clean up each cut. With the Selection tool V, drag the clip edge to change its In or Out. Use Ripple Edit B when you want later material to move with the trim. Play across the cut after changing it to catch gaps and repeated movements.
  2. Keep the action readable. Try cutting from a wide shot to a closer angle as the action starts. If the cut feels abrupt, move it a few frames or bridge it with continuous ambience. Use transitions where a change in time or place calls for one.
  3. Reframe in Effect Controls. Select the clip and adjust Motion › Position and Scale. To add a slow push-in, enable keyframes for Scale at the start, move the playhead and raise Scale slightly. Keep the important subject in frame throughout the move.

Mix sound and add text

  1. Separate the tracks. Put dialogue or main location sound on A1, ambience on A2 and music on A3. Solo tracks to diagnose unwanted noise. Adjust clip gain or volume so speech stays intelligible and the mix never clips.
  2. Smooth the edges. Add a short audio crossfade where two clips meet. Let the next shot’s sound begin early or let the old shot’s sound continue over the cut. Listen for continuity as well as level.
  3. Add one simple title. Use the Type tool T, click the Program Monitor and enter the title. Adjust it in Properties and trim the graphic in the timeline. For speech, create captions from the final transcript and proofread names and timing.

Correct colour

  1. Confirm the source. Check whether the footage is Apple Log, Apple Log 2, or already Rec.709. Use the Premiere LUT guide to set up an SDR sequence and choose one conversion.
  2. Match adjacent shots. Open Lumetri Color and look at exposure and white balance before adding a look. Use the waveform to spot clipped highlights and RGB Parade to inspect a tint. Match the shots next to each other in the timeline.
  3. Add a creative look. For normalized Rec.709 footage, choose a creative .cube in Lumetri › Creative › Look. Try 50% intensity. Toggle the effect so you can see which colours or tones it changes.

Export and check

  1. Open Export. Select the sequence and press Ctrl+M on Windows or ⌘+M on macOS. Choose H.264 and start with Match Source – Adaptive High Bitrate for a review MP4.
  2. Check the output. Verify the frame size, frame rate, Rec.709 output, and that both video and audio are enabled. Set the range to the entire sequence for a full export. Name the file Street Study 01.mp4 and export it into the Exports folder.
  3. Watch the MP4. Check the opening, the final frame, gaps, sync, captions and overall loudness. For delivery, use the platform’s or client’s requested settings.

Fix common problems

Media Offline appears

Reconnect the original drive. Select the missing clip in the Project panel, choose Link Media and locate the corresponding original. Check the file name and folder before relinking.

Playback stutters

Try lower Program Monitor playback resolution first. If the originals still struggle, make proxies from the Project panel and use Toggle Proxies while editing. Keep the originals connected when exporting.

Insert drops video without sound

Check the source patch indicators at the left of the timeline. Make sure an audio source is patched to an available, unlocked audio track and that the clip contains audio.

The exported shot looks much darker

Import the export back into Premiere and compare the same frame with your timeline. Check the output colour space, source interpretation and whether the same LUT was applied twice.
